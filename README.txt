ניתן ליצור חשבון עם סיסמה קצרה ופשוטה
למשל:
Email: a@a.com
Password: 123

' OR 1=1 --
בתיבת שם המשתמש

זוהי בדיקת
SQL Injection


בדיקת Stored XSS
לאחר התחברות לחשבון, בלוח הבקרה הזינו את הקוד הבא בשדה הוספת לקוח: <script>alert("Hacked by XSS")</script>
לאחר מכן תועברו למסך ההצלחה והקוד ירוץ ויופיע בתור פופ-אפ בדפדפן
לאחר מכן, עצרו את השרת בטרמינל בעזרת CTRL+C



הגרסה המאובטחת
נווטו לגרסה המאובטחת באמצעות
cd../Secure_Version
הריצו את השרת
python secure_app.py
פתחו את הדפדפן וגשו לכתובת
http://127.0.0.1:5000
הירשמו לחשבון חדש, המערכת אוכפת חוקי סיסמה מורכבים המצויים בקובץ config.json
כעת כשננסה להתחבר עם השורה
' OR 1=1 --
המערכת תזהה את השורה הזו כטקסט רגיל בזכות: Parameterized Queries

כשנריץ את השורה 
<script>alert("Hacked by XSS")</script>
במסך הוספת לקוח הלקוח יתווסף בהצלחה תחת השם הזה ולא יזהה את השורה הזאת כקוד אלא כטקסט רגיל
